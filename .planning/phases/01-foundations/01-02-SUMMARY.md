## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] Biome rejected three separate `export { handler as VERB }` statements**
- **Found during:** Task 2 final verify (`pnpm turbo run build typecheck test lint`)
- **Issue:** Biome 2.4's `assist/source/organizeImports` rule treats consecutive single-export statements for the same symbol as a sortable group and demands consolidation. The plan's Pattern 9 (Pitfall recap) specified three lines so that `grep -q "as GET"` / `as POST"` / `as DELETE"` each match independently.
- **Fix:** Consolidated to `export { handler as GET, handler as POST, handler as DELETE };` — each `as VERB` substring still matches independently, so the plan's verify greps all pass. Added a comment explaining the constraint.
- **Files modified:** `apps/mcp/app/api/mcp/[transport]/route.ts`
- **Commit:** `2c91d23`

**2. [Rule 3 — Blocking] Next.js regenerated `next-env.d.ts` with double quotes; Biome enforces single quotes**
- **Found during:** Task 2 final verify (`pnpm turbo run ... lint`)
- **Issue:** `next build` rewrites `next-env.d.ts` to include `import "./.next/types/routes.d.ts";` (with double quotes — Next's own format). Our root `biome.json` enforces `quoteStyle: 'single'`, so Biome fails on every post-build run. Editing `next-env.d.ts` is futile — Next regenerates it on the next build.
- **Fix:** Added `"includes": ["**", "!**/next-env.d.ts", "!**/.next/**"]` to `biome.json` `files`. Biome no longer lints Next-managed generated files. Source files in apps/mcp continue to be linted.
- **Files modified:** `biome.json`
- **Commit:** `2c91d23`
- **Doc impact:** Plans that add another Next.js app (Phase 4 apps/web) inherit this exclusion automatically — it's repo-wide.

**3. [Rule 2 — Missing critical] Added `*.tsbuildinfo` to apps/mcp/.gitignore**
- **Found during:** Task 1 staging
- **Issue:** tsc `incremental: true` produces `tsconfig.tsbuildinfo` as a side effect; not source, must not be committed.
- **Fix:** Added to `apps/mcp/.gitignore`.
- **Files modified:** `apps/mcp/.gitignore`
- **Commit:** `dcab512`
